## Юридические тексты

- Регистрация уведомления РКН о обработке ПД (`shared/content/legal.ts`:
  `rknNotified = false` → в политике, раздел 2, выводится формулировка
  «уведомление подаётся; статус будет опубликован после подтверждения»).
  Владелец должен подать уведомление по ст. 22 152-ФЗ и подтвердить статус —
  тогда переключить на `true`.
- Дата начала запрета оборота ЭСДН/жидкостей в Саратовской области уже
  учтена (`shared/legal/regional-restrictions.ts`, 01.03.2027) — при
  изменении регионального закона отредактировать там же.

## Модель, зафиксированная с владельцем

- Брони хранятся только на сайте; «Заказы покупателя» и контрагенты в
  «МойСклад» не создаются.
- Бонусы: сайт только отображает баланс и правила; начисление/списание —
  на кассе «МойСклад». Серверного списания/начисления по статусам брони
  нет (исключено выбранной моделью).
