# Данные, необходимые от владельца «Бункера»

Сайт собран и работает на фикстурах. До запуска в production нужно
предоставить следующие данные (по каждому пункту указано, куда их вписать).

## Критично для запуска

| Что нужно | Где используется | Сейчас |
| --- | --- | --- |
| API-токен «МойСклад» (только чтение) | `.env`: `NUXT_MOYSKLAD_TOKEN` | пусто — фикстурный режим |
| Домен сайта | `.env`: `NUXT_PUBLIC_SITE_URL` | `https://bunker.example` (плейсхолдер, сайт закрыт от индексации) |
| Телефон/почта/соцсети сети | `shared/content/bunker.ts` | заглушки `+7 (000) 000-00-00`, `info@bunker.example`, vk.com/bunker_vape (недоступен на момент сборки) |
| Реквизиты продавца (ИП/ООО, ИНН, ОГРН(ИП), адрес) | `shared/content/legal.ts` | заглушки с пометкой `requisitesPlaceholder`; в футере отображаются как «ИП Бункер · ИНН · ОГРНИП» |
| Список магазинов (или наполнение в «МойСклад») | склады «МойСклад» + координаты `shared/content/store-coordinates.json` (заполняет `npm run stores:geocode`) | 3 демо-точки фикстуры; локальное обогащение пусто |
| Корневые категории «МойСклад» | `shared/legal/classification.ts`: `ROOT_CATEGORY_CLASSES` | типовой маппинг вейпшопа; сверить `npm run catalog:sync` |
| Состав типов цен | `.env`: `MOYSKLAD_PRICE_TYPES` | авто: первый ненулевой тип товара |
| Служебные склады | `.env`: `MOYSKLAD_INTERNAL_STORES`, `MOYSKLAD_INTERNAL_STORE_PREFIXES` | пусто — выгружаются все неархивные склады |
| Название/ID бонусной программы (если в аккаунте несколько активных) | `.env`: `MOYSKLAD_BONUS_PROGRAM_ID` или `MOYSKLAD_BONUS_PROGRAM_NAME` | первая активная |

## Брендинг

| Что нужно | Где используется | Сейчас |
| --- | --- | --- |
| Файлы шрифтов **BICUBIK** и **Akzentica** (woff2, лицензии) | `public/fonts/` (`@font-face` в `app/assets/css/base.css` уже подключают `/fonts/*.woff2`) | файлов нет — работают fallback-цепочки (Arial Black/Impact и системные) |
| Официальный логотип/маскот «Бункера» (SVG/PNG) | шапка/футер, og-image | текстовый вордмарк «БУНКЕР» + сгенерированная марка (коралловый параллелограмм с «Б») |
| Постеры/фотографии для героя и статических страниц | `public/images/` (WebP, генерируются из `design-kit/referens/`) | использованы изображения из макетов дизайн-системы |
| Дымы/графика | `public/images/smoke-*.webp` | из материалов дизайн-системы |

## Опциональные интеграции (включаются ключами)

| Что нужно | Где используется | Поведение без ключей |
| --- | --- | --- |
| Счётчик Яндекс.Метрики | `.env`: `NUXT_PUBLIC_METRIKA_COUNTER_ID` (+ `NUXT_PUBLIC_METRIKA_ENABLED=auto`) | скрипт Метрики не грузится |
| Ключ JS API Яндекс.Карт | `.env`: `NUXT_PUBLIC_YANDEX_MAPS_API_KEY` | карта работает без ключа (предупреждение в консоли) |
| Yandex SmartCaptcha (клиентский + серверный ключи) | `NUXT_PUBLIC_SMARTCAPTCHA_CLIENT_KEY`, `SMARTCAPTCHA_SERVER_KEY` | капча не показывается; формы защищены honeypot и rate-limit |
| Telegram-бот уведомлений о резервах | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_RESERVATION_CHAT_IDS` | уведомления уходят задачей в «МойСклад» (`MOYSKLAD_NOTIFY_EMPLOYEE_ID`) и видны в инбоксе сайта |
| Telegram-бот заявок партнёрства | `NUXT_TELEGRAM_BOT_TOKEN`, `NUXT_TELEGRAM_CHAT_ID` | заявки хранятся на сайте (инбокс сотрудника) |
| Телефоны сотрудников для инбокса | `.env`: `STAFF_INBOX_PHONES` (через запятую) | инбокс в кабинете скрыт |
| Пороги МРЦ (действующая редакция постановления) | `shared/legal/min-prices.ts` | проверка МРЦ отключена (только предупреждение в `catalog:sync`) |

## Юридические тексты

- Регистрация уведомления РКН о обработке ПД (`shared/content/legal.ts`:
  `rknNotified = false` → в политике выводится формулировка «уведомление
  подано/не подано» корректно для текущего статуса).
- Дата начала запрета оборота ЭСДН/жидкостей в Саратовской области уже
  учтена (`shared/legal/regional-restrictions.ts`, 01.03.2027) — при
  изменении регионального закона отредактировать там же.

## Модель, зафиксированная с владельцем

- Брони хранятся только на сайте; «Заказы покупателя» и контрагенты в
  «МойСклад» не создаются.
- Бонусы: сайт только отображает баланс и правила; начисление/списание —
  на кассе «МойСклад». Серверного списания/начисления по статусам брони
  нет (исключено выбранной моделью).
