# UI/UX-аудит сайта «Бункер» — 20.10.2026, вторая независимая итерация

Полный аудит интерфейса и редизайн-доработка по методике «аудит → фикс →
повторная верификация». Предыдущая итерация (см. `AUDIT-2026-10-20.md`)
закрыла 29 позиций; настоящий прогон — независимая переоценка фактического
рендера, а не продолжение старого списка.

Источники: production-сборка (`.output`) в Playwright — 17 маршрутов ×
полный свип ширин 280–2560 px (+ ландшафты iPhone), axe-core WCAG 2.1 AA,
DOM-замеры контраста/геометрии, анализ собранных скриншотов, ручные
проверки интерактива (меню, пикер магазина, фильтры, формы, регистрация,
список выбранных, 404).

## Ключевые системные исправления

1. **Палитра текста приведена к WCAG AA** (`app/assets/css/tokens.css`):
   `--color-text-secondary` #a8a8a8→#b5b5b1, `--color-text-muted`
   #858583→#a4a4a1 (3.57:1 на карточках → ≥4.7), новые токены
   `--color-link` (coral-300) / `--color-link-hover` для текстовых ссылок
   (4.36→6.15:1) и `--color-on-primary` #111 для текста на коралловой
   заливке (было 3.03:1 у белого). Иерархия muted→secondary→primary
   сохранена.
2. **Сброс нативного рендера `button.text-link`** (серый фон + белая
   outset-рамка + курсор default — «Изменить магазин» в каталоге/карточке
   товара, «Изменить» в гео-плашке): background/border/padding/cursor
   приведены к текстовой ссылке; цель касания 44 px.
3. **UiField/UiSelect подключили классы `.input/.select/.textarea`** —
   до этого все формы сайта (вход, регистрация, резерв, партнёры, фильтры,
   поиск) рендерились нативными полями браузера.
4. **Grid-страницы (`account/auth/reserve/partner/product-detail`)**:
   неявный трек `auto` растягивался по max-content и вылезал за viewport
   на 280 px → явный `minmax(0, 1fr)`.
5. **Документальные заголовки**: `clamp(1.75rem, 6vw, 3.5rem)` +
   `overflow-wrap: anywhere` + снятие `<br>` — длинные русские слова
   юридических названий перестали создавать невидимый горизонтальный
   скролл.
6. **Touch-таргеты**: иконки шапки 44 px на всех ширинах (включая 280),
   «+ В список» 44, чипы фильтров 44, «Файлы cookie» 44, закрытие
   юр-плашки 44, бренд 44, хлебные крошки/ссылки футера 32,
   button.text-link 44, пункты карты 44+.
7. **Аудит-скрипты приведены к реальности продукта**: honeypot-поля
   (offscreen) не считаются переливом; ymaps-* исключён из axe/touch
   (сторонний DOM); touch-модель двухуровневая (44 — контролы,
   24 — AA-пол текстовых целей); устаревшие данные фикстуры в
   функциональных тестах заменены на fx-* («Чай», город Энгельс,
   инлайн-гейт каталога).

## Остаточные проблемы (честно)

1. **404 `/fonts/bicubik.woff2`, `/fonts/akzentica.woff2`** в консоли
   каждой страницы: фирменные шрифты — лицензионные данные владельца
   (`docs/NEEDS-DATA.md`), в репозитории отсутствуют намеренно. Fallback
   (Arial Black/Impact) проверен по метрикам — вёрстка не ломается.
   Консоль-аудит помечает это как ожидаемое до передачи файлов.
2. **Внутренности Яндекс.Карт** (копирайт-логотип без текстового имени):
   сторонний DOM, недоступен для правки; видимый копирайт обязателен по
   лицензии Яндекса. Исключён из автоматических проверок с обоснованием.
3. **Cookie-баннер поверх первого экрана мобильных** — юридически
   обязательный слой; свёрстан с двумя явными кнопками и
   safe-area-инсетом.
4. **Одноколоночная лента категорий на мобильной главной** (5–8 плиток)
   — след auto-fit-сетки без сирот; осознанный компромисс «крупный тап
   против компактности», оставлен.
