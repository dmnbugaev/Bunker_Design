# Типографика

## Шрифты

**Display:** BICUBIK — `"Bicubik Local", "Arial Black", Impact, sans-serif`.

**Body:** Akzentica — `"Akzentica Local", Inter, "Segoe UI", Arial, sans-serif`.

Файлы шрифтов не были предоставлены. `@font-face` ожидает:

- `assets/fonts/bicubik.woff2`;
- `assets/fonts/akzentica.woff2`.

До получения лицензированных файлов системные fallback видны намеренно. После добавления WOFF2 нужно проверить кириллицу, веса, метрики и CLS. `font-display: swap` уже задан.
