# Дизайн-система «Бункер»

## Назначение

Система задаёт единый визуальный и поведенческий язык для информационного сайта и каталога сети вейпшопов. Она не проектирует дистанционную продажу: каталог помогает изучить ассортимент и уточнить наличие в физическом магазине.

## Концепция

«Сигнал в темноте» — тёмная основа, крупная выразительная типографика, коралловый акцент и дымчатая глубина. В hero и карточках используются предоставленные локальные изображения бренда; интерфейсный слой наследует их контраст, диагональные срезы, красную дымку и плотный рекламный ритм, сохраняя читаемость продуктового сайта.

## Архитектура

```text
assets/
  js/components.js        DOM-first поведение компонентов
  js/design-system.js     данные и сборка демо
  styles/tokens.css       primitive → semantic → component tokens
  styles/base.css         reset, типографика, общие примитивы
  styles/components.css   UI-компоненты
  styles/design-system.css только композиция showcase-страницы
design-system/index.html  закрытая от индексации витрина
docs/design-system/       правила и исследования
```

Нативный стек выбран потому, что исходная директория не содержала приложения или фреймворка. Система не зависит от UI-библиотек и допускает перенос классов и токенов в Vue/Nuxt после появления основного приложения.

## Принципы

1. Акцентный цвет не используется как декор по умолчанию.
2. Компоненты получают значения только из централизованных токенов.
3. Интерактивные цели имеют размер не менее 40 px, а основные mobile-цели — 44–48 px.
4. Состояния передаются не только цветом: текстом, рамкой, формой или иконкой.
5. Display-типографика короткая; интерфейсный текст остаётся спокойным и читаемым.

## Motion-направление

Вместо одинаковых появлений каждого блока используется один постановочный момент в hero: дым раскрывается слоями, заголовок появляется через маску, брендовый постер входит с перспективой. После вступления движение остаётся только реактивным — постер и дым слегка отвечают на курсор. Карточки каталога получают глубину и дымовой акцент только при наведении. При `prefers-reduced-motion` вступление и интерактивная глубина отключаются.

## Подключение

```html
<link rel="stylesheet" href="/assets/styles/tokens.css">
<link rel="stylesheet" href="/assets/styles/base.css">
<link rel="stylesheet" href="/assets/styles/components.css">
```

Композиционные стили showcase-страницы не должны подключаться в продуктовые страницы.
