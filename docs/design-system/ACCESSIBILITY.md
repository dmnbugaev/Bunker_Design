# Доступность

Целевая планка — WCAG 2.2 AA для пользовательских страниц.

## Реализовано

- семантические `header`, `nav`, `main`, `section`, `aside`, `footer`;
- skip-link к основному содержимому;
- видимый общий `:focus-visible`;
- связанные label, hint и error для форм;
- `aria-expanded`, `aria-controls`, `aria-selected`, `aria-current`;
- status/alert/live-region для обратной связи;
- нативный dialog;
- управление tabs стрелками, Home и End;
- Escape и возврат фокуса для drawer;
- reduced motion;
- цвет не является единственным носителем состояния.

## Контраст

Основной текст `#F5F5F3` на `#1B1B1B` имеет высокий контраст. Фирменный `#A8A8A8` используется как secondary text. Коралловый `#FF5C5C` на тёмном фоне применяется для крупных/жирных акцентов и границ; на коралловой кнопке используется почти чёрный текст.

## Перед production

1. Проверить реальные WOFF2 и визуальные метрики кириллицы.
2. Запустить axe/Lighthouse после интеграции в основное приложение.
3. Проверить screen reader на macOS/iOS и Windows.
4. Проверить пользовательский zoom 200–400%.
5. Заменить условные продуктовые изображения на контент с корректными alt.
