# Адаптивная система

## Контрольные ширины

Проверяются 320, 375, 390, 430, 768, 1024, 1280, 1440 и 1920 px.

## Поведение

- до 767 px: mobile navigation, одна колонка каталога, фильтры раскрываются кнопкой, dialog actions складываются вертикально;
- 768–1023 px: две карточки товара, компактная композиция hero;
- от 1024 px: sidebar-фильтры и до трёх карточек;
- от 1440 px: контент ограничен 1440 px, внешние поля растут;
- 1920 px: длина строк и карточек остаётся контролируемой контейнером.

Display-размеры используют `clamp()`. Контейнер имеет поля `clamp(16px, 4vw, 64px)`. Все grid-треки используют `minmax(0, 1fr)`, а длинные слова допускают перенос.

## Чек-лист

- горизонтальный scroll отсутствует;
- меню доступно с клавиатуры;
- touch-target основных действий 44–56 px;
- таблицы и строки не выходят за контейнер;
- количество колонок меняется без изменения DOM;
- responsive preview использует container query и ручной resize на desktop.
