## A. Системные проблемы (дизайн-система, каркас, CSS)

### A1 [P0] Тулбар каталога разваливается на две строки на десктопе
- **Файлы:** `app/assets/css/components.css:835-840` (`.catalog-toolbar`),
  `app/components/catalog/CatalogToolbar.vue`
- **Факт (замер 1440px):** grid `minmax(12rem,1fr) auto` содержит 3 элемента
  (счётчик, кнопка «Фильтры», сорт-селект) → сорт-селект переносится на вторую
  строку (высота тулбара 107px). Кнопка «Фильтры» (мобильный триггер) видна
  на десктопе, где сайдбар фильтров уже открыт постоянно.
- **План:** flex-тулбар (счётчик слева, сортировка справа), триггер «Фильтры»
  показывать только < 64rem.

### A2 [P1] Две конкурирующие системы разметки каталога
- **Файлы:** `components.css:815-819` (`.catalog-layout`, сайдбар 13–17rem)
  vs `components.css:996-1006` (`.catalog-grid`, 17.5rem — не используется);
  `.product-grid` (3→2@64→1@48) vs `.product-grid--catalog` (3→2@80→1@48).
  На 64–80rem главная показывает 3 колонки, каталог — 2 без причины.
- **План:** унифицировать одну систему: `.catalog-layout` + единая сетка
  карточек с одинаковыми брейкпоинтами; мёртвый `.catalog-grid` удалить.

### A3 [P1] Дубли-синонимы из склейки ProHook + Бункер
- **Файлы:** `components.css:937-1020` («адаптация под компоненты приложения»):
  `.button--normal/--large` vs `.button--sm/--lg`, `.field__help` vs
  `.field__hint`, `.sr-only` vs `.visually-hidden`.
- **План:** оставить по одному каноническому имени, алиасы удалить после
  проверки использования.

### A4 [P1] Фирменные шрифты отсутствуют (404)
- **Файлы:** `public/fonts/` (пусто), `tokens.css:6-22` (@font-face).
- **Факт:** `/fonts/bicubik.woff2`, `/fonts/akzentica.woff2` — 404 в консоли
  каждой страницы. Файлы — лицензионные данные владельца
  (`docs/NEEDS-DATA.md`), в проекте их нет.
- **План:** невозможно исправить без файлов владельца. Смягчение: fallback
  уже заявлен (Arial Black/Impact); проверить, что заголовки в верхнем
  регистре не разваливаются на fallback-шрифте. Ограничение зафиксировано.

### A5 [P2] Мёртвый CSS карточки товара из старой вёрстки
- **Файлы:** `components.css:428-567` (`.product-card__media`,
  `.product-card__media--photo`, дым-оверлей, hover-свечение) — эти классы
  не существуют в текущей разметке (ProductCard рендерит
  `.product-card__visual`). Задуманный эффект «дыма за фото» потерян,
  ~140 строк мёртвого кода.
- **План:** перенести эффект на реальную структуру (`.product-card__visual`),
  мёртвые селекторы удалить.

### A6 [P2] `.section` определён дважды (base.css:120 и pages.css:37)
- **План:** консолидировать в base.css, страница-специфику — отдельно.

### B7 [P2] Сигнальная лента статична и выглядит недоделанной

- **План:** аккуратная CSS-анимация сдвига (уважая prefers-reduced-motion)

  юридическое ограничение (серверная проверка, `server/utils/product-images.ts`),

- Пустые telegram/instagram в `bunker.ts` — данные владельца (NEEDS-DATA);
  честное решение — не показывать пустые ссылки (см. B5).
