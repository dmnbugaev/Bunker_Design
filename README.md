# Бункер — design system

Независимая демонстрация дизайн-системы сети вейпшопов «Бункер». Проект создан на нативных HTML, CSS и JavaScript: исходная папка не содержала приложения или выбранного фреймворка, поэтому добавление UI-библиотеки не требовалось.

## Запуск

```bash
npm run dev
```

Откройте `http://127.0.0.1:4173/design-system/`.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Документация находится в `docs/design-system/`. Файлы BICUBIK и Akzentica не входят в исходные материалы; точки подключения и fallback-цепочки подготовлены в `assets/styles/tokens.css`.
